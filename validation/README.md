# QSARCert validation on real models

Everything in the v2 manuscript is regenerated by three scripts, run from the repository root:

```bash
python validation/run_models.py        # 180 models: 3 datasets x 2 splits x 10 seeds x 3 model types
python validation/benchmark.py         # QSARCert 1.1.0 and current version on every model, with references
python validation/make_figures.py      # figures/ and tables/
python validation/make_graphical_abstract.py
```

- `data/`: ESOL (`delaney-processed.csv`), FreeSolv (`SAMPL.csv`) and Lipophilicity (`Lipophilicity.csv`) as distributed by MoleculeNet/DeepChem; checksums in `data/SHA256SUMS`.
- `legacy_v110/`: the 1.1.0 modules, unchanged, used for the comparison.
- `results/benchmark.csv`: one row per model (metrics, verdicts of both versions, deviations from the references).
- `results/yrand_estimator.csv`: Y-randomization of the random forests with the model refitted (ESOL and FreeSolv, seeds 0-2).
- `results/offset_scan.csv`: Golbraikh-Tropsha verdicts after shifting the response origin.
- `results/predictions.csv.gz`: training and test predictions of every model.
- `results/runs/`, `results/features/`, `results/bench_cache/` are regenerated by the scripts and are not tracked.

Timing on a 16-core desktop: models about 45 min (Lipophilicity random forests dominate), benchmark about 15 min, model-based Y-randomization 1-2 h. Set one BLAS thread per process (the benchmark does this itself).
