Quantitative Structure-Activity Relationship (QSAR) modeling for pIC50 (Enzyme Inhibition) was conducted using Random Forest Regressor. Statistical validity, external predictivity, and OECD Validation Principles compliance were audited using QSARCert v1.0.0 (Monreal-Hernández, 2026). External predictivity metrics met Golbraikh-Tropsha standards (Q^2_ext = 0.970, CCC = 0.985, r_m^2 avg = 0.952, k = 1.003). The applicability domain was verified via Hat matrix leverage analysis (h* = 0.175) and Williams plot, confirming 100.0% coverage without influential outliers. Robustness against chance correlation was certified by Y-randomization across 50 permutations (cR^2_p = 0.858 > 0.50, mean scrambled R^2 = 0.211). The model achieved an overall OECD compliance certification of: WARNING.
