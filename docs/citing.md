# Citing QSARCert

If QSARCert helps your research, please cite it. The repository's [`CITATION.cff`](https://github.com/sircalch/qsarcert/blob/master/CITATION.cff) is the canonical record; GitHub's "Cite this repository" button uses it.

Version 1.2.0 (2026-09-30) is archived on Zenodo with the DOI [10.5281/zenodo.22217582](https://doi.org/10.5281/zenodo.22217582).

```bibtex
@software{qsarcert_1_2_0,
  author  = {Monreal-Hern{\'a}ndez, Andr{\'e}s},
  title   = {QSARCert},
  version = {1.2.0},
  year    = {2026},
  doi     = {10.5281/zenodo.22217582},
  url     = {https://github.com/sircalch/qsarcert}
}
```

QSARCert is research software. A PASS from its checks means the checks found nothing wrong; it is not an independent validation of the scientific result. Cite it for what it is: a tool that documents how a calculation was checked.
